# Bosun Silence Hider

Расширение для Chrome, которое скрывает на дашборде Bosun группы алертов, уже отправленные в `silence`.

## Что делает

- находит alert-группы с иконкой mute (`fa-volume-off`)
- скрывает их из общего списка
- добавляет кнопку для показа/скрытия `silenced alerts`
- показывает счётчик скрытых групп
- сохраняет состояние кнопки после перезагрузки страницы

## Зачем

Расширение уменьшает шум на дашборде и помогает быстрее видеть только те алерты, которые реально требуют внимания.

## Структура

```text
.
├── manifest.json
└── content.js
````

## Установка в Chrome

1. Сохраните файлы в отдельную папку или скачайте и распакуйте архив https://github.com/suvertok/bosun-silence-hider/archive/refs/tags/Bosun.zip:

   ```text
   Bosun-Silence-Hider/
   ├── manifest.json
   └── content.js
   ```

2. Откройте в Chrome:

   ```text
   chrome://extensions/
   ```

3. Включите **Режим разработчика**.

4. Нажмите **Загрузить распакованное расширение**.

5. Выберите папку с файлами расширения.

6. Обновите страницу Bosun.

## Обновление

После изменений в `content.js` или `manifest.json`:

1. Откройте `chrome://extensions/`
2. Нажмите **Reload** у расширения
3. Обновите вкладку Bosun

## Использование

После загрузки страницы в интерфейсе Bosun появляется кнопка:

* **Показать silenced alerts** — показать скрытые группы
* **Скрыть silenced alerts** — снова скрыть их

Когда сайленсы скрыты, на кнопке показывается их количество.

## Настройка позиции кнопки

В `content.js` можно менять положение кнопки:

```javascript
const TOGGLE_TOP = '12px';
const TOGGLE_RIGHT = '16px';
```

* `TOGGLE_TOP` — отступ сверху
* `TOGGLE_RIGHT` — отступ справа
