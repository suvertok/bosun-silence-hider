
# Bosun Silence Hider

Расширение для Chrome, которое скрывает на дашборде Bosun алерты, уже отправленные в `silence`.

## Что делает

- находит alert с иконкой mute (`fa-volume-off`)
- скрывает их из общего списка
- добавляет кнопку для показа/скрытия `silenced alerts`
- показывает счётчик скрытых
- сохраняет состояние кнопки после перезагрузки страницы

## Зачем

Расширение уменьшает шум на дашборде и помогает быстрее видеть только те алерты, которые реально требуют внимания.

## Структура
````md
├── manifest.json
└── content.js
````

## Установка в Chrome

1. Скачайте и распакуйте архив https://github.com/suvertok/bosun-silence-hider/archive/refs/tags/Bosun.zip.

   
3. Откройте в Chrome:

   ```text
   chrome://extensions/
   ```

4. Включите **Режим разработчика**.

5. Нажмите **Загрузить распакованное расширение**.

6. Выберите папку с файлами расширения.

7. Обновите страницу Bosun.


## Использование

После загрузки страницы в интерфейсе Bosun появляется кнопка:

* **Показать silenced alerts** — показать скрытые алерты
* **Скрыть silenced alerts** — снова скрыть их

Когда сайленсы скрыты, на кнопке показывается их количество.

## Настройка позиции кнопки

В `content.js` можно менять положение кнопки:

```javascript
const TOGGLE_TOP = '12px';
const TOGGLE_RIGHT = '16px';
```

* `TOGGLE_TOP` — отступ сверху
* `TOGGLE_RIGHT` — отступ справа

## Обновление

После изменений в `content.js` или `manifest.json`:

1. Откройте `chrome://extensions/`
2. Нажмите **Reload** у расширения
3. Обновите вкладку Bosun

## Ограничения

* логика завязана на текущую разметку Bosun

## Безопастность
Код расширения делает **только визуальную фильтрацию на стороне браузера**, он не «трогает» сами данные Bosun и не шлёт их никуда наружу.

### Что именно делает плагин

- **Подключение**: `manifest.json` подключает `content.js` как content script к страницам `bosun-test.edna.ru` и `bosun.edna.ru` с правами только `storage` (локальное хранилище Chrome).
- **Поиск алертов**: `content.js` ищет на странице элементы с классом `.panel` и определяет, что панель засайленсена, если в заголовке есть иконка `.fa-volume-off`.
- **Сокрытие/показ**: если алерт засайленсен и режим «не показывать» включен, панели просто добавляется класс `bosun-silence-hidden`, который через CSS (`display: none !important`) скрывает её.
- **Кнопка‑переключатель**: в `document.body` добавляется фиксированная кнопка, которая:
  - меняет флаг `showSilenced` (показывать/прятать),
  - вызывает `applyVisibility()` — перекидывает/убирает CSS‑класс,
  - сохраняет состояние в `chrome.storage.local` (только булевый флаг, без контента алертов).
- **Отслеживание изменений страницы**: `MutationObserver` следит за изменениями DOM и при обновлении алертов повторно прогоняет фильтрацию (снова только добавление/удаление CSS‑класса).

**Плагин не отправляет и не сохраняет содержимое алертов**, не модифицирует их данные на сервере — он лишь:
- читает структуру DOM на странице,
- определяет, какие панели «silenced» по иконке,
- и **визуально скрывает/показывает** их через CSS и кнопку.
