
# Bosun Silence Hider

Расширение для Chrome, которое скрывает на дашборде Bosun алерты, уже отправленные в `silence`.

## Что делает

- находит alert с иконкой mute (`fa-volume-off`)
- скрывает их из общего списка
- добавляет кнопку для показа/скрытия `silenced alerts`
- показывает счётчик скрытых
- сохраняет состояние кнопки после перезагрузки страницы

## Зачем

Расширение уменьшает шум на дашборде и помогает быстрее видеть только те алерты, которые реально требуют внимания.

## Установка в Chrome

1. Скачайте и распакуйте архив https://github.com/suvertok/bosun-silence-hider/archive/refs/tags/Bosun.zip.

   
3. Откройте в Chrome:

   ```text
   chrome://extensions/
   ```

4. Включите **Режим разработчика**.

5. Нажмите **Загрузить распакованное расширение**.

6. Выберите папку с файлами расширения.

7. Обновите страницу Bosun.


## Использование

После загрузки страницы в интерфейсе Bosun появляется кнопка:

* **Показать silenced alerts** — показать скрытые алерты
* **Скрыть silenced alerts** — снова скрыть их

Когда сайленсы скрыты, на кнопке показывается их количество.

## Настройка позиции кнопки

В `content.js` можно менять положение кнопки:

```javascript
const TOGGLE_TOP = '12px';
const TOGGLE_RIGHT = '16px';
```

* `TOGGLE_TOP` — отступ сверху
* `TOGGLE_RIGHT` — отступ справа

## Обновление

После изменений в `content.js` или `manifest.json`:

1. Откройте `chrome://extensions/`
2. Нажмите **Reload** у расширения
3. Обновите вкладку Bosun

## Ограничения

* логика завязана на текущую разметку Bosun
