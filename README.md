# Bosun Silence Hider

Расширение для Chrome/Chromium-браузеров, которое уменьшает шум на дашборде Bosun и помогает быстрее работать с алертами.

Плагин работает поверх интерфейса Bosun в браузере и ничего не меняет на сервере: он анализирует DOM страницы, скрывает засайленсенные алерты только там, где это действительно удобно, и добавляет визуальные подсказки для секции **Needs Acknowledgement**.

## Что умеет плагин

### 1. Скрытие `silenced alerts` только в `Acknowledged`

Плагин находит на странице алерты, уже отправленные в silence, и скрывает их **только в секции `Acknowledged`**.

В секции **`Needs Acknowledgement`** silenced alerts **не скрываются** и всегда остаются видимыми.

Что входит в эту часть логики:

- поиск алертов с иконкой mute (`fa-volume-off`)
- скрытие таких алертов только в блоке **Acknowledged**
- кнопка для показа и скрытия `silenced alerts`
- счётчик скрытых алертов
- сохранение состояния кнопки после перезагрузки страницы

### 2. Подсветка алертов в `Needs Acknowledgement`

Плагин помогает быстрее понять, какие алерты в секции **Needs Acknowledgement** уже обработаны, а какие ещё требуют внимания.

Используются два дополнительных визуальных состояния:

- **note-значок** — у алерта уже есть Note
- **warning-значок** — алерт старше заданного порога и у него нет Note

Для родительских групп действует приоритет:

- если внутри группы есть хотя бы один дочерний alert старше порога и без Note — у parent показывается **warning**
- если warning нет, но есть хотя бы один дочерний alert с Note — у parent показывается **note**

Это позволяет быстрее ориентироваться в больших пачках алертов, не раскрывая каждую группу вручную.

### 3. Кнопка `Copy` у алертов

Рядом с текстом алерта добавляется кнопка **Copy**, которая копирует текст алерта в буфер обмена.

Поддерживаются:

- родительские алерты
- дочерние алерты

Пример того, что копируется:

```text
critical: sms channel group dlv percent low in test - 0.00% / 0.00%
```

После нажатия кнопка кратко меняет состояние, чтобы было видно, что копирование выполнено.

### 4. Улучшение выделения текста мышкой

Чтобы было удобнее мышкой выделять пачку алертов и копировать только полезный текст, плагин делает невыделяемыми служебные элементы интерфейса:

- кнопку **Copy**
- счётчик вида `5 alerts`
- возраст алерта, например `11d-ago`
- идентификатор алерта, например `#263970:`

Это уменьшает шум при ручном копировании списка алертов.

## Зачем это нужно

Стандартный Bosun Dashboard часто перегружен:

- часть алертов уже засайленсена и не требует внимания прямо сейчас
- в `Needs Acknowledgement` сложно быстро отличить уже просмотренные алерты от тех, которые ещё никто не отметил
- при ручном копировании текста в выделение попадают служебные элементы интерфейса

Плагин решает эти задачи:

- убирает визуальный шум от `silenced alerts` в **Acknowledged**
- оставляет silenced alerts видимыми в **Needs Acknowledgement**
- помогает быстрее понимать состояние алертов
- упрощает копирование текста алертов

## Как это работает

Плагин подключается к страницам Bosun как content script и работает только в браузере.

Основная логика:

- анализирует DOM дашборда
- определяет, какие алерты засайленсены
- скрывает или показывает их через CSS-класс
- применяет скрытие только к секции **Acknowledged**
- не скрывает silenced alerts в секции **Needs Acknowledgement**
- добавляет кнопку управления в интерфейс страницы
- сохраняет состояние переключателя в `chrome.storage.local`
- отслеживает изменения DOM через `MutationObserver`
- обновляет визуальные маркеры для `Needs Acknowledgement`
- добавляет кнопки **Copy**
- помечает служебные элементы как невыделяемые

## Поддерживаемые адреса

Текущая версия подключается только к этим адресам:

- `https://bosun.edna.ru/*`

## Установка в Chrome / Edge / Brave / Opera

### Установка из распакованной папки

1. Скачайте проект или распакуйте архив с файлами расширения.
2. Откройте страницу расширений в браузере:

```text
chrome://extensions/
```

Для Edge:

```text
edge://extensions/
```

3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку, в которой лежат `manifest.json` и `content.js`.
6. Откройте или обновите вкладку Bosun.

## Использование

После загрузки страницы Bosun плагин начинает работать автоматически.

### Работа с silenced alerts

На странице появляется кнопка-переключатель:

- **Показать silenced alerts** — показать скрытые алерты
- **Скрыть silenced alerts** — снова скрыть их

Если скрытие включено, на кнопке отображается количество скрытых алертов.

Важно:

- скрытие применяется только к секции **Acknowledged**
- в секции **Needs Acknowledgement** silenced alerts остаются видимыми

### Работа с Needs Acknowledgement

В секции `Needs Acknowledgement` рядом с алертами и группами могут появляться дополнительные значки:

- значок Note — у алерта уже есть Note
- warning-значок — алерт старый и без Note

Это визуальные подсказки, они не меняют поведение самого Bosun.

### Копирование текста алертов

Рядом с текстом алерта отображается кнопка **Copy**.

Она:

- копирует текст конкретного алерта в буфер обмена
- не должна мешать раскрытию и сворачиванию групп
- не попадает в выделение текста мышкой

## Настройка

Часть параметров можно менять прямо в `content.js`.

Обычно имеет смысл настраивать:

- положение кнопки на странице
- интервал обновления данных
- debounce для реакций на изменения DOM
- порог времени, после которого alert без Note получает warning-значок
- тексты служебных кнопок и их визуальное оформление

После изменения параметров нужно перезагрузить расширение на странице `chrome://extensions/` и затем обновить вкладку Bosun.

## Обновление расширения

Если вы изменили `content.js` или `manifest.json`:

1. Откройте страницу расширений.
2. Нажмите **Reload / Перезагрузить**.
3. Обновите вкладку Bosun.

## Ограничения

У плагина есть несколько важных ограничений:

- логика завязана на текущую DOM-разметку Bosun
- если в Bosun изменится HTML-структура, часть функций может перестать работать
- визуальные маркеры в `Needs Acknowledgement` зависят от структуры групп и дочерних alert-элементов
- логика кнопок **Copy** и невыделяемых элементов тоже зависит от текущей разметки заголовков
- расширение не является официальной частью Bosun и работает как внешний UI-слой

## Безопасность

Плагин выполняет только клиентскую визуальную обработку страницы.

Он:

- не изменяет данные алертов на сервере Bosun
- не отправляет содержимое алертов наружу
- не добавляет и не снимает silence
- не создаёт Notes
- не изменяет acknowledgement-статусы

Что реально делает расширение:

- читает DOM страницы Bosun
- определяет засайленсенные алерты по иконке mute
- визуально скрывает или показывает их через CSS
- сохраняет только локальное состояние переключателя в `chrome.storage.local`
- копирует текст алертов в буфер обмена только по нажатию кнопки **Copy**

То есть это инструмент визуальной фильтрации, подсветки и удобного копирования, а не средство управления самими алертами.

## Совместимость

Текущий `manifest.json` использует **Manifest V3**, поэтому расширение в первую очередь рассчитано на Chromium-браузеры:

- Google Chrome
- Microsoft Edge
- Brave
- Opera
- Vivaldi
- Яндекс Браузер

Работа в Firefox теоретически возможна только после отдельной проверки и, при необходимости, адаптации.

- улучшение выделения текста
